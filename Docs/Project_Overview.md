## **Manufacturing Analytics Project**



##### 1\. Excel – ETL, Data Modeling and Dashboard Development



Performed ETL (Extract, Transform, Load) operations using Power Query to clean and prepare the manufacturing dataset. Removed duplicate records, handled errors, and eliminated blank rows to obtain 10,000 valid records from the original 10,679 rows.

Loaded the cleaned data into Excel's Data Model and established relationships between tables using Power Pivot. Created measures, PivotTables, and Pivot Charts to analyze manufacturing performance.



###### Developed two interactive dashboards:



Production Dashboard: Analyzed production output and manufacturing performance.

Quality Dashboard: Evaluated rejected quantities and quality-related metrics.



##### 2\. Power BI – Data Modeling and Visualization



Imported the cleaned manufacturing data into Power BI Desktop and established relationships between tables to create a structured data model.

Developed interactive dashboards using KPI visuals, cards, bar charts, and other visualizations to present key manufacturing metrics and business insights. Used these visuals to simplify data interpretation and support data-driven decision-making.



##### 3\. SQL – Database Development and Data Analysis



Separated the cleaned Excel Data Model tables into individual files and converted them into CSV format for database integration.

Created a database and the required tables in MySQL Workbench. Imported the CSV files using LOAD DATA LOCAL INFILE and executed SQL queries to analyze manufacturing performance.

Used SQL operations such as aggregations, joins, grouping, and filtering to answer business questions and derive insights. Exported query results to Excel for further analysis and reporting.



##### 4\. Tableau – Data Visualization and Dashboard Development



Imported the cleaned manufacturing data into Tableau and established relationships between tables to maintain consistency with the data models used in Excel and Power BI.

Developed visualizations using different chart types, KPI indicators, and other analytical visuals. Recreated relevant visualizations from the Excel and Power BI dashboards while exploring additional ways to analyze manufacturing performance and identify business insights.



##### 5\. Project Workflow



###### Raw Manufacturing Data → Power Query (ETL) → Excel Data Model → MySQL Database → Power BI Dashboards → Tableau Visualizations



The project integrates data cleaning, relational data modeling, SQL-based analysis, and interactive visualization to derive meaningful insights from manufacturing data.



###### Skills Demonstrated

ETL: Excel Power Query

Data Modeling: Excel Power Pivot and Power BI relationships

Database Management: MySQL Workbench

SQL: Joins, aggregate functions, filtering, grouping, and business analysis

Data Visualization: Excel Pivot Charts, Power BI, and Tableau

Reporting: KPI tracking, dashboard development, and business insights
